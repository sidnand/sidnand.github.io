## Overview

GB-Emu is a Game Boy emulator with a deterministic, pure-Python core and a browser frontend. The project emphasizes hardware timing and verifies its behavior against established CPU, memory, and rendering test suites.

The emulator supports original Game Boy and Game Boy Color modes, including cartridge banking, interrupts, DMA, audio, and save states. The web app can run in the browser or connect to a local bridge; game files stay on the user's machine.

To try a game with the local bridge, follow the repository's [setup instructions](https://github.com/sidnand/GB-Emu#quick-start). See the [source and browser-app details](https://github.com/sidnand/GB-Emu).
